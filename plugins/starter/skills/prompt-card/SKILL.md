# prompt-card

1. Спроси, чего не хватает: для чего промпт, как использовать, почему работает, на каких моделях проверен.
2. Собери карточку по шаблону:

````md
---
title: <короткое название>
tags: [<темы>]
models: [<модели>]
author: "<github-ник>"
---

# <короткое название>

**Для чего:** <одна строка>

**Как использовать:** <что подставить, куда вставить>

```text
<промпт как есть, без правок смысла>
```

**Почему работает:** <что делает результат хорошим>
````

3. Предложи путь `content/prompts/<slug>.md` (или `content/cases/` для кейса). Списки разделов собираются автоматически. Без git — через форму на сайте (`/new`).
4. Не выдумывай результаты и модели — только то, что сказал пользователь.
