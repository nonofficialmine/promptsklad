# Разрешить read-only команды, чтобы Claude реже спрашивал

**Для чего:** Claude постоянно спрашивает разрешение на безобидные команды: посмотреть дифф, проверить, занят ли порт, найти процесс. Allowlist снимает эти вопросы и оставляет подтверждение для команд, которые что-то меняют.

**Как использовать:** Добавьте блок в .claude/settings.json проекта (или в ~/.claude/settings.json для всех проектов). Проверка: попросите Claude показать git diff — он выполнит команду без вопроса.

```text
{
  "permissions": {
    "allow": [
      "Bash(git status:*)",
      "Bash(git diff:*)",
      "Bash(git log:*)",
      "Bash(git show:*)",
      "Bash(ls:*)",
      "Bash(lsof -iTCP:*)",
      "Bash(ss -tlnp:*)",
      "Bash(ps -o:*)"
    ]
  }
}
```

**Почему работает:** Правило `Bash(git diff:*)` разрешает команду с любыми аргументами. Здесь только команды, которые читают состояние, поэтому риск минимален. lsof, ss и ps нужны, чтобы проверять порты перед запуском dev-сервера: на машине часто уже занят 3000 или 5173.

**Когда не работает:** Правило разрешает любые аргументы, поэтому составляйте список осознанно. Например, `git diff --output=файл` пишет в файл. Если нужна строгость, перечисляйте полные команды без `:*`.
