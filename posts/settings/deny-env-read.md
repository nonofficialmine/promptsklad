# Запретить Claude читать .env и секреты

**Тема:** Разработка · **Теги:** безопасность

**Для чего:** Чтобы ключи и пароли из .env случайно не попали в разговор с ИИ. Заодно — разрешить тесты без лишних вопросов.

**Как использовать:** Добавьте блок в .claude/settings.json проекта и закоммитьте: правило заработает у всей команды. Проверка: попросите Claude прочитать .env — он получит отказ.

```text
{
  "permissions": {
    "deny": [
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./secrets/**)"
    ],
    "allow": [
      "Bash(npm run test:*)",
      "Bash(npm run lint:*)"
    ]
  }
}
```

**Почему работает:** Запрет (deny) сильнее разрешения (allow): если правило попало в deny, его не отменит ни одна другая настройка. Это защита от случайности, а не от взлома: команда в терминале вроде cat .env правилом Read не закрывается.
