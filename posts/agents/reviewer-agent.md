# Ревьюер, который ничего не правит

**Тема:** Разработка · **Теги:** код-ревью, безопасность

**Для чего:** Отдельный агент для проверки кода: смотрит свежие изменения и пишет отчёт, но не меняет файлы.

**Как использовать:** Сохраните файл как .claude/agents/reviewer.md (или в ~/.claude/agents/ — для всех проектов). Claude вызовет агента сам после правок. Можно попросить явно: «попроси reviewer проверить изменения». Список агентов — команда /agents.

```text
---
name: reviewer
description: Проверяет свежие изменения в коде на ошибки и дыры в безопасности. Используй сразу после правок кода и перед коммитом.
tools: Read, Grep, Glob, Bash
model: sonnet
---

Ты — строгий ревьюер. Ничего не правь: только читай и пиши отчёт.

1. Посмотри изменения: git diff и git diff --staged.
2. Ищи только то, что сломается в работе: ошибки логики, забытые случаи, утечки ключей, дыры в безопасности.
3. Стиль и названия не трогай.
4. Для каждой находки: файл:строка, что сломается и при каких данных, как исправить.
5. Находок нет — так и скажи. Не выдумывай.
```

**Почему работает:** У агента своя память разговора: длинный дифф не забивает основной чат, обратно приходит только отчёт. Среди инструментов нет Edit и Write, поэтому править файлы он не может. Bash нужен для git diff; для строгого «только чтение» уберите Bash.
