# Playwright MCP для QA: фиксированный FULLHD и папка для скриншотов

**Для чего:** Когда Claude тестирует интерфейс через Playwright MCP, размер окна по умолчанию плавает, и баги вёрстки то воспроизводятся, то нет. Скриншоты оседают в корне проекта. Два флага это исправляют.

**Как использовать:** Выполните в папке проекта. Добавьте `.tmp/` в .gitignore. Проверка: попросите Claude открыть сайт и сделать скриншот — он окажется в .tmp/screenshots в разрешении 1920×1080.

```text
claude mcp add playwright --scope project -- npx @playwright/mcp@latest --viewport-size "1920,1080" --output-dir .tmp/screenshots

В .mcp.json это выглядит так:
{
  "mcpServers": {
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": ["@playwright/mcp@latest", "--viewport-size", "1920,1080", "--output-dir", ".tmp/screenshots"]
    }
  }
}

Строка для CLAUDE.md, чтобы правило соблюдали и агенты:
Тестирование UI — только через playwright-mcp в FULLHD; скриншоты — только в .tmp/screenshots/, имя <фича>-<шаг>-<время>.png.
```

**Почему работает:** `--viewport-size` фиксирует размер окна, и проверки воспроизводятся одинаково. `--output-dir` задаёт папку для файлов, которые сохраняет сервер. Строка в CLAUDE.md нужна потому, что субагенты читают её, а не настройки MCP.

**Когда не работает:** Мобильную вёрстку так не проверить: для неё нужен отдельный прогон с другим размером или эмуляцией устройства.
