# Playwright MCP: Claude сам проверяет сайт в браузере

**Тема:** Разработка · **Теги:** frontend, тесты

**Для чего:** Чтобы Claude открыл ваш сайт в браузере, понажимал кнопки, заполнил формы и рассказал, что сломано.

**Как использовать:** Выполните команду в терминале, в папке проекта (нужен Node.js). В Claude Code введите /mcp — сервер playwright должен быть в списке. Затем попросите, например: «Открой localhost:3000 и проверь форму входа».

```text
claude mcp add playwright -- npx @playwright/mcp@latest

Чтобы сервер был у всей команды, добавьте его в проект:
claude mcp add playwright --scope project -- npx @playwright/mcp@latest

Команда создаст файл .mcp.json — его можно закоммитить:
{
  "mcpServers": {
    "playwright": {
      "type": "stdio",
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

**Почему работает:** Claude видит страницу как список элементов (кнопки, поля, текст), а не как картинку, поэтому нажимает точно. Браузер запускается с отдельным профилем: ваши обычные вкладки и сохранённые пароли он не видит.
