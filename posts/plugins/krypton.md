# Krypton: план и доказательства до того, как агент пишет код

**Тема:** Разработка · **Теги:** рефакторинг, код-ревью, CI/CD, документация

**Для чего:** Для разработчиков, которые пускают ИИ-агентов в рабочий код: плагин заставляет сначала составить план — кто владеет данными, какой старый путь заменяется, чем доказать результат, — чтобы агент не собрал правдоподобную, но неверную фичу.

**Как использовать:** Введите две команды установки в Claude Code, затем /reload-plugins. Навыки вызываются с префиксом плагина. Начните с /krypton:krypton-planning и опишите задачу — фичу, баг, рефакторинг или миграцию. Агент соберёт пакет цели в папке docs/goals/имя-цели/: PLAN.md (полный план), GOAL.md (короткий запрос для следующей сессии) и EVIDENCE.md (сюда записываются доказательства). Потом откройте новую сессию, вставьте текст GOAL.md (или используйте /goal, если ваша среда его поддерживает) и подключите /krypton:krypton-execution — он держит агента в рамках плана, пока не собраны доказательства. Отдельных программ ставить не нужно. В репозитории есть ещё скрипт на Python 3 для локальной проверки пакета цели и GitHub Action в бета-версии для пулл-реквестов.

```text
/plugin marketplace add jturntdev/krypton
/plugin install krypton@krypton-dev

/krypton:krypton-planning
```

**Почему работает:** Внутри три навыка. krypton-planning превращает просьбу в план, где названы: какой результат нужен, какое текущее поведение заменяется или удаляется, кто источник истины, какой контракт проходит через границу модулей и чем будет доказан результат. krypton-execution следит, чтобы при реализации агент не ушёл от плана и записал реальные доказательства — ответ API, состояние браузера, вывод команды. krypton-vps-codex-app (бета) — пошаговая настройка удалённого Linux-сервера для Codex App. Есть отдельные шаблоны промптов для проверяющих ролей (plan-reviewer, reviewer, maintainer); лучше всего работает в среде, где можно запускать именованных субагентов. Польза — меньше дублирующих путей в коде и фич, которые вроде бы работают, но живут не на том слое.

**Комментарий:** Плагин стороннего автора: jturntdev, github.com/jturntdev/krypton. promptsklad его не проверял — перед установкой посмотрите репозиторий. Плагин состоит только из навыков: хуков и MCP-серверов в нём нет, сам он ничего не запускает. Навык для VPS (бета) рассчитан на Codex App и затрагивает SSH-конфиг, доступ к GitHub и авторизацию Codex CLI; по описанию автора, он спрашивает разрешение перед каждым таким шагом — всё равно читайте, что агент собирается выполнить. Версия 0.3.2, автор называет её первым публичным выпуском. Лицензия MIT.
