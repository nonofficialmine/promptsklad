# falsegreen: найти тесты, которые не ловят поломки

**Тема:** Разработка · **Теги:** тесты, код-ревью

**Для чего:** Ищет «ложно-зелёные» тесты — те, что проходят, даже когда код сломан: проверка не выполняется, мок сравнивается сам с собой, ожидаемое значение взято из того же кода. Для тех, кто пишет тесты на Python, TypeScript, JavaScript или Robot Framework.

**Как использовать:** В Claude Code выполните /plugin marketplace add vinicq/falsegreen-skill и /plugin install falsegreen-skill@falsegreen. Затем вызовите навык командой /falsegreen-skill:falsegreen-skill или просто попросите Claude проверить тестовый файл или папку на ложноположительные тесты: навык срабатывает по смыслу запроса и сам находит файлы. Поддерживаются pytest и unittest, Jest, Vitest, Mocha, Jasmine, Testing Library и Robot Framework. Можно попросить и обратное — написать тест для функции по спецификации: навык возьмёт ожидаемые значения из спецификации, а не из текущего кода. Для больших Python-проектов можно сначала прогнать статический сканер (pip install falsegreen, затем falsegreen tests/) и передать его вывод навыку — так быстрее. Отдельный ключ API нужен только консольной утилите npx falsegreen-skill, а не навыку в Claude Code.

```text
/plugin marketplace add vinicq/falsegreen-skill
/plugin install falsegreen-skill@falsegreen

/falsegreen-skill:falsegreen-skill
```

**Почему работает:** Это один навык falsegreen-skill, без хуков и MCP-серверов. Он читает тест как текст и задаёт шесть вопросов J1–J6: выполняется ли проверка вообще, взято ли ожидаемое значение из независимого источника, тестируется ли настоящий код, а не его мок, достаточно ли строгая проверка, не завязан ли тест на внутренности реализации, проходит ли он сам по себе, без других тестов. Каждая находка получает код из каталога (около 125 шаблонов: серия C для Python, JS для TypeScript и JavaScript, R для Robot Framework и смысловые случаи S), уровень уверенности HIGH или LOW, номер строки, объяснение и подсказку по исправлению. Автор ставит точность выше полноты: спорные случаи вроде тестов, которые намеренно фиксируют текущее поведение, не помечаются. Навык закрывает промежуток между линтерами вроде ruff и мутационным тестированием: видит то, что линтер не понимает, и не требует запускать код.

**Комментарий:** Плагин стороннего автора: Vinicius Queiroz, github.com/vinicq/falsegreen-skill. promptsklad его не проверял — перед установкой посмотрите репозиторий. В Claude Code это только инструкции для агента: по PRIVACY.md навык сам ничего не отправляет в сеть, телеметрии и хуков нет. В том же репозитории есть отдельная консольная утилита npx falsegreen-skill (нужен Node 18+): она отправляет содержимое указанных файлов выбранному провайдеру модели под вашим ключом API, а её команда fix запускает pytest и исполняет сгенерированный моделью тест на вашей машине. К плагину это не относится, но учитывайте, если решите ставить утилиту. Лицензия MIT.
