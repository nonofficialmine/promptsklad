# Как поставить плагин: на примере starter

**Тема:** Тексты и контент · **Теги:** документация

**Для чего:** Поставить плагин (набор скиллов, команд, агентов и хуков) одной командой — и понять, как это работает для любого плагина.

**Как использовать:** Введите команды по очереди прямо в Claude Code. Маркетплейс (каталог плагинов) добавляется один раз, дальше из него ставится любой плагин.

```text
1. Добавить маркетплейс promptsklad:
/plugin marketplace add nonofficialmine/promptsklad

2. Поставить плагин:
/plugin install starter@promptsklad

3. Посмотреть, включить, выключить или удалить плагины:
/plugin
```

**Почему работает:** В starter есть скилл prompt-card: он спрашивает, чего не хватает в вашем промпте или кейсе, и собирает карточку для этого сайта. Запись starter@promptsklad значит «плагин starter из маркетплейса promptsklad» — так же ставятся плагины из любого другого каталога.
