# Boss: девять агентов ведут фичу от идеи до выкладки

**Тема:** Разработка · **Теги:** автоматизация, код-ревью, тесты, CI/CD

**Для чего:** Для тех, кто хочет, чтобы Claude Code вёл задачу как небольшая команда: требования, архитектура, код, тесты и проверки перед выкладкой — с документами и журналом каждого шага прямо в папке проекта.

**Как использовать:** Введите две команды установки в Claude Code. Самый безопасный первый запуск — /boss:review на уже существующем проекте: это только чтение кода, результат — отчёт tech-review.md в папке .boss. Проверка тестами с отчётом — /boss:qa. Полный конвейер — /boss и описание задачи; флаг --roles core оставляет только PM, архитектора, разработчика и QA, флаг --skip-deploy останавливает работу до выкладки. Есть также /boss:plan (PRD и архитектура до кода), /boss:ship (сборка и проверки перед выкладкой), /boss:extend (свои агенты и проверки) и /boss:upgrade (обновление). Нужен Node.js 22.18 или новее — на нём работает встроенная утилита плагина; без Node конвейер идёт в упрощённом режиме, только с Markdown-файлами. Для промежуточных снимков работы нужен git.

```text
/plugin marketplace add echoVic/boss-skill
/plugin install boss@boss-skill

/boss:review
```

**Почему работает:** Внутри навык boss и роли девяти агентов: boss-pm, boss-architect, boss-ui-designer, boss-tech-lead, boss-scrum-master, boss-frontend, boss-backend, boss-qa и boss-devops. Работа идёт в четыре этапа: требования и архитектура, разбивка на задачи, разработка с тестами, выкладка и итоговый отчёт. Между этапами стоят проверки: Gate 0 (типы, линтер, сборка), Gate 1 (результаты тестов и отсутствие критичных багов), Gate 2 (скорость страниц и API, где это применимо). Всё, что получилось, — PRD, архитектура, список задач, отчёты QA и выкладки — лежит в .boss/имя-фичи/, а журнал событий позволяет продолжить с нужного этапа через --continue-from. Хуки не дают агенту править служебный файл состояния напрямую и перехватывают опасные команды вроде rm -rf, git push --force или DROP TABLE.

**Комментарий:** Плагин стороннего автора: echoVic, github.com/echoVic/boss-skill. promptsklad его не проверял — перед установкой посмотрите репозиторий. Плагин ставит хуки, которые запускаются сами: при старте и завершении сессии, перед записью файлов и командами в терминале, при работе субагентов; один из них после работы агента автоматически делает промежуточный снимок через git (stash, коммит или ветку). Ослабить хуки можно переменными BOSS_HOOK_PROFILE=minimal или BOSS_DISABLED_HOOKS. По словам автора, плагин ничего не отправляет в сеть; исключение — локальный сервер предпросмотра дизайна на 127.0.0.1, который запускается только вручную. Учтите: по инструкции навыка документы в .boss по умолчанию пишутся на китайском. Лицензия MIT.
