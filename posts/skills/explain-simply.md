# Объяснить сделанное простыми словами

**Тема:** Обучение · **Теги:** документация

**Для чего:** Чтобы Claude Code объяснял свою работу понятно людям без опыта программирования.

**Как использовать:** Создайте папку .claude/skills/explain-simply в проекте (или ~/.claude/skills/explain-simply — для всех проектов) и положите туда файл SKILL.md. Claude включит скилл сам, когда вы попросите объяснить. Можно вызвать и вручную: /explain-simply.

```text
---
name: explain-simply
description: Объясняет сделанное в коде простыми словами для человека без опыта программирования. Используй, когда просят «объясни просто», «что ты сделал», «что это значит», и после больших правок.
---

# Объяснить простыми словами

1. Первая строка — итог: что изменилось для человека, а не для кода.
2. Каждый термин — сразу с расшифровкой в скобках обычными словами.
3. Одна мысль — одно предложение. Не больше 5 предложений, если не просят подробнее.
4. Не проверил — так и скажи: «не проверял». Без пустых оговорок вроде «может потребоваться».
5. В конце — один следующий шаг для человека.
```

**Почему работает:** Поле description говорит Claude, когда включать скилл, поэтому в нём перечислены живые фразы-триггеры. Правила короткие и проверяемые: по ответу видно, соблюдены они или нет.
