# custdev3: проверка идеи тремя независимыми методами

**Для чего:** Проверить, что идея решает реальную боль и что рынок существует и измерим. Каждый метод по отдельности врёт по-своему: форумы — о размере рынка, реестры молчат о боли, отчёты аналитиков завышают прогнозы. Вместе они перекрывают слабые места друг друга.

**Как использовать:** Создайте .claude/skills/custdev3/SKILL.md. Вызов: «/custdev3 идея: ...». Для метода 1 нужен доступ к сети через Bash (curl).

```text
---
name: custdev3
description: Проверка стартап-идеи тремя методами — боль из форумов, рынок из реестров и налоговых данных, прогноз из отчётов аналитиков. Используй на этапе валидации идеи, после прототипа.
---

# custdev3

Цель: (а) боль реальна, (б) рынок реален и измерим, (в) аналитики подтверждают тренд.

## Метод 1 — форумы: дословная боль
- Reddit через curl на .json: /r/{sub}/search.json?q=...&restrict_sr=1, /r/{sub}/top.json?t=year&limit=100, /r/{sub}/comments/{id}.json. Около 60 запросов в минуту.
- Если не отвечает — выпиши поисковые запросы, пользователь откроет их в браузере и вернёт ссылки.
- Hacker News: hn.algolia.com/api/v1/search?query=...&tags=story. GitHub issues, Stack Exchange API.
- Собирай: цитата дословно + ссылка + оценка/голоса + дата + кластер боли + сигналы готовности платить.

## Как разбирать собранные тексты
1. KWIC: все упоминания ключевых слов с контекстом — как люди на самом деле говорят о проблеме.
2. Индуктивное кодирование первых ~50 текстов: темы вырастают из данных.
3. Из тем собери кодировочную рамку и размечай по ней остальные тексты.
Не начинай с готовой рамки: найдёшь только то, что ожидал.

## Метод 2 — реестры и налоговые данные: рынок сейчас
- США: SEC EDGAR, IRS SOI, Census. ЕС: Eurostat, Companies House (UK). РФ: ФНС, СПАРК, Rusprofile. Узбекистан: stat.uz. Казахстан: stat.gov.kz. Мир: OpenCorporates.
- Собирай: число действующих компаний в нише по кодам ОКВЭД/NAICS, динамику регистраций и закрытий, выручку публичных конкурентов, географию.
- Каждая цифра — ссылка и дата выгрузки. На глаз не оценивай.

## Метод 3 — отчёты аналитиков: прогноз
- Big 4 (KPMG, Deloitte, EY, PwC), McKinsey, BCG, Gartner, IDC, Forrester, CB Insights.
- Собирай: TAM/SAM/SOM с годом и источником, CAGR, список игроков.
- Это оценки, а не факты. Big 4 продают консалтинг, их прогнозы оптимистичны. Верь горизонту 2–3 года, не 10. Сверяй с методом 2.

## Сведение
- Форумы жалуются + реестры показывают много компаний + аналитики видят рост → подтверждено.
- Форумы жалуются, но компаний мало → рынок маленький → частично.
- Форумы молчат, аналитики хвалят → возможно, искусственный хайп.

## Правила
- Каждое утверждение — проверяемая ссылка. Нет источника — нет утверждения. Не выдумывай ссылки и цифры.
- Один источник — слабый сигнал.
- Указывай дату данных. Факт (метод 2) отделяй от прогноза (метод 3).

## Результат
Боль (30–60 цитат по кластерам) · рынок сейчас · прогноз из 2–3 источников · вердикт: подтверждено / частично / нет · риски: что может оказаться неправдой.
```

**Почему работает:** Методы закрывают разные дыры: форумы показывают боль и готовность платить, реестры — реальный размер рынка, отчёты — направление. Расхождение между ними само по себе информация, например хайп без боли. Правило «нет источника — нет утверждения» отсекает выдуманные цифры, к которым склонен ИИ.

**Когда не работает:** В B2B-нишах, где покупатели не пишут на форумах: метод 1 даёт пустоту. Её нельзя читать как «боли нет» — нужны интервью.
