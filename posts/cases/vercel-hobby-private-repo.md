# Vercel не деплоил коммиты второго автора

**Тема:** Разработка · **Теги:** CI/CD, git

**Для чего:** Понять, почему сайт на Vercel не обновляется после части коммитов, хотя ошибок нет.

Задача: сайт на Vercel (бесплатный тариф Hobby) обновляется сам после каждого коммита в main. Над проектом работают двое.

Что случилось: коммиты владельца аккаунта Vercel выкладывались, а коммиты второго участника — нет. В логах сборок ошибок не было: сборка по таким коммитам просто не начиналась.

Причина: репозиторий был приватным. На тарифе Hobby Vercel не поддерживает совместную работу над приватными репозиториями: выкладывает только коммиты владельца, а остальные блокирует.

Что сделали: открыли репозиторий (сделали публичным). Для публичных репозиториев это ограничение не действует. Проверили контрольным коммитом от другого автора — сайт обновился.

Другие варианты: платный тариф Pro или выкладка только с аккаунта владельца. Подменять автора коммита ради обхода не стоит: это обход условий тарифа.

**Выводы:** Если выкладка «молчит» без ошибки, сначала проверьте, кто автор коммита и на каком тарифе проект. Статус выкладки виден на GitHub рядом с коммитом: значок Vercel и подсказка при наведении.
