# Автозахват идей из разговора в файл-«свалку»

**Для чего:** В долгих обсуждениях с Claude идеи теряются: контекст сжимается, ветки забываются. Записывать «только важное» не получается — решать, что важно, в момент мысли некогда. Хук пишет всё, а разбирать можно потом пачкой.

**Как использовать:** Добавьте блок в .claude/settings.json проекта. Нужен jq. Добавьте `.claude/idea-inbox.md` в .gitignore. Проверка: отправьте любой промпт и откройте файл — там появится запись с датой.

```text
{
  "hooks": {
    "UserPromptSubmit": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "mkdir -p .claude && jq -r \"\\\"\\n## \\\" + (now|strflocaltime(\\\"%Y-%m-%d %H:%M\\\")) + \\\"\\n\\\" + .prompt\" >> .claude/idea-inbox.md"
          }
        ]
      }
    ]
  }
}
```

**Почему работает:** UserPromptSubmit срабатывает на каждый ваш промпт до того, как его увидит Claude. Текст промпта приходит хуку в поле `prompt`. Вывод уходит в файл, а не в stdout, поэтому в контекст разговора ничего не добавляется. Раз в несколько дней из свалки выносятся решения, отвергнутые идеи с причиной и открытые вопросы.

**Когда не работает:** Сохраняются только ваши промпты, без ответов Claude. Если в промпт попал ключ или пароль, он окажется в файле, поэтому файл не должен попадать в git.
