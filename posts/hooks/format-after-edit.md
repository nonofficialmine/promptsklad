# Автоформат файла после каждой правки

**Тема:** Разработка · **Теги:** автоматизация, frontend

**Для чего:** Чтобы файлы, которые правит Claude, сразу приводились к единому стилю — без отдельной команды.

**Как использовать:** Добавьте блок в .claude/settings.json проекта. Нужны jq (утилита для чтения JSON в терминале) и Prettier в проекте: npm i -D prettier. Проверка: попросите Claude поправить любой .js-файл — после правки он будет отформатирован.

```text
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r '.tool_input.file_path' | xargs -I{} npx prettier --write --ignore-unknown {}"
          }
        ]
      }
    ]
  }
}
```

**Почему работает:** PostToolUse срабатывает после того, как инструмент отработал. Данные о правке приходят хуку в JSON, путь к файлу — в tool_input.file_path. Флаг --ignore-unknown не даёт Prettier падать на файлах, которые он не умеет форматировать.
