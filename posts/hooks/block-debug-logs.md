# Не дать закоммитить временные console.log и print

**Для чего:** При отладке Claude расставляет `console.log` и `print`, а потом забывает их убрать. Хук останавливает коммит, пока в добавленных строках остаются такие логи.

**Как использовать:** Добавьте блок в .claude/settings.json проекта. Нужен jq. Проверка: добавьте `console.log(1)` в любой файл и попросите Claude закоммитить — коммит будет остановлен с сообщением.

```text
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "jq -r \".tool_input.command\" | grep -qE \"(^|[;&| ])git commit\" || exit 0; if git diff --cached -U0 | grep -E \"^\\+[^+]\" | grep -qE \"console\\.log\\(|(^|[^a-zA-Z_.])print\\(\"; then echo \"В staged-изменениях есть console.log/print — удалите временные логи перед коммитом\" >&2; exit 2; fi"
          }
        ]
      }
    ]
  }
}
```

**Почему работает:** PreToolUse срабатывает до запуска команды. Хук пропускает всё, кроме `git commit`, смотрит только добавленные строки в `git diff --cached` и при находке выходит с кодом 2. Код 2 блокирует вызов, а текст из stderr уходит Claude, и он сам убирает логи. Старый код с логами не мешает: проверяются только новые строки. `blueprint(` и `obj.print(` не считаются.

**Когда не работает:** `git commit -a` добавляет файлы уже внутри команды, поэтому хук их не видит. Логи через структурный логгер (`logger.debug`) не ловятся, и это правильно: они остаются для мониторинга.
