# Тест на банальность: убрать выводы, которые ничего не сообщают

**Для чего:** Очистить отчёт, исследование или стратегию от выводов, которые верны всегда и поэтому бесполезны: «нужно учитывать потребности клиента», «важно качество». У ИИ это самый частый вид шума.

**Как использовать:** Вставьте промпт и текст с выводами.

```text
Проверь каждый вывод в тексте ниже тестом на банальность.

1. Переверни вывод: «клиенту важна скорость» → «клиенту не важна скорость».
2. Если перевёрнутое звучит абсурдно и никто бы так не сказал — исходный вывод банален: он ничего не сообщает.
3. Если перевёрнутое — разумная позиция, которую кто-то мог бы занять, вывод содержательный.
4. Для каждого банального вывода предложи конкретизацию, которая делает его проверяемым: кто, сколько, по сравнению с чем, в какой момент.

Таблица: вывод → перевёрнутый → банален? → конкретизация.

Текст: [текст]
```

**Почему работает:** Информацию несёт только утверждение, которое могло оказаться неверным. Переворот быстро показывает, есть ли у вывода разумная альтернатива. Конкретизация превращает «важна скорость» в «60% отказов происходит, если ответ дольше суток» — это уже можно проверить.

**Когда не работает:** На намеренно общих текстах: миссия, ценности, вступление. Там банальность — жанр.
