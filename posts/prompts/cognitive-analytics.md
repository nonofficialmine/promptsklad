# Когнитивная аналитика: причины из отзывов, тикетов и переписки

**Для чего:** Найти ответ, которого нет в цифрах. Причина, по которой клиент не купил, редко лежит в CRM: там статус «проиграно» без объяснения. Она лежит в тикетах, отзывах и переписке. Промпт разбирает тексты так, чтобы найти неожиданное, а не только подтвердить ожидаемое.

**Как использовать:** Вставьте промпт и тексты (отзывы, обращения, переписку, комментарии). Если текстов сотни, начните с выборки из 50–100.

```text
Разбери тексты ниже. Вопрос: [что хотим понять — из диагностического шага].

1. Ключевые слова в контексте: для слов [список] покажи 5–10 упоминаний с окружающим текстом. Как люди на самом деле о них говорят?
2. Темы из данных: прочитай тексты и выдели темы, которых нет в моём вопросе. Не подгоняй под ожидания.
3. Рамка: из тем собери список категорий с определением каждой. Размечай по ней все тексты: категория, тональность, цитата.
4. Частота и тяжесть отдельно: сколько упоминаний и насколько серьёзно каждое (неудобство / потеря денег / уход клиента). 500 жалоб на упаковку и 5 на потерю данных — разные проблемы.
5. Смещение выборки: кто пишет такие тексты, а кто молчит? Что это значит для выводов?
6. Цитаты: на каждый вывод — 2–3 дословные цитаты. Без цитаты нет вывода.

Тексты: [тексты]
```

**Почему работает:** Пункты 1–3 повторяют проверенный в исследованиях порядок: сначала темы вырастают из текстов (индуктивно), потом по ним строится рамка для разметки (дедуктивно). Если начать с готовой рамки, найдётся только ожидаемое. Пункт 4 не даёт частым мелочам заслонить редкое серьёзное, а пункт 6 отсекает темы, которые модель придумала.

**Когда не работает:** Если текстов мало (до 20), темы будут случайными. И если пишут только крайние (восторженные и злые), без пункта 5 выводы перекосит.
