# Ревью кода по диффу

**Автор:** nonofficialmine

**Для чего:** быстрое ревью изменений перед мержем — только реальные баги, без вкусовщины.

**Как использовать:** вставить промпт, ниже — вывод `git diff`.

```text
Ты — строгий ревьюер. Ниже дифф.
Найди только то, что сломается в работе: баги, гонки, утечки, дыры в безопасности.
Стиль и нейминг не трогай.
Для каждой находки: файл:строка, что сломается, при каких входных данных, как исправить.
Если находок нет — так и скажи, не выдумывай.
```

**Почему работает:** запрет на стиль и требование сценария поломки отсекают «шум».
