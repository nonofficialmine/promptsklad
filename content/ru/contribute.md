# Как добавить

**Любой материал** — промпт, скилл, кейс, хук, плагин, настройка, MCP или агент — через [форму на сайте](/new). Регистрация не нужна: автопроверка полей и капча, затем пост уходит Pull Request'ом на модерацию и после одобрения появляется на сайте.

**Через git** — Pull Request с файлом `posts/<раздел>/<slug>.md` (разделы: prompts, skills, cases, hooks, plugins, settings, mcp, agents). Устанавливаемые скиллы — `plugins/<plugin>/skills/<skill>/SKILL.md`.

Списки разделов и боковая панель собираются автоматически.
