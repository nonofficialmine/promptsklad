# Скиллы

Скиллы для Claude Code лежат в папке `plugins/` репозитория и ставятся через маркетплейс плагинов.

## Установка

```text
/plugin marketplace add <owner>/promptsklad
/plugin install starter@promptsklad
```

## Каталог

| Плагин | Скиллы | Для чего |
|---|---|---|
| `starter` | `prompt-card` | Оформить промпт/кейс в карточку для promptsklad |
