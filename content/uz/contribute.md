# Qanday qo‘shish mumkin

**Har qanday material** — prompt, skill, keys, hook, plagin, sozlama, MCP yoki agent — [saytdagi forma](/uz/new) orqali. Ro‘yxatdan o‘tish shart emas: maydonlarni avtotekshirish va kapcha, so‘ng post Pull Request sifatida moderatsiyaga boradi va tasdiqlangach saytda paydo bo‘ladi.

**Git orqali** — `posts/<bo‘lim>/<slug>.md` fayli bilan Pull Request (bo‘limlar: prompts, skills, cases, hooks, plugins, settings, mcp, agents). O‘rnatiladigan skillar — `plugins/<plugin>/skills/<skill>/SKILL.md`.

Bo‘lim ro‘yxatlari va yon panel avtomatik yig‘iladi.
