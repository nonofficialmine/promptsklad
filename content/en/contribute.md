# Contributing

**Any material** — a prompt, skill, case, hook, plugin, setting, MCP server or agent — via the [form on the site](/en/new). No sign-up: automatic validation and a captcha, then the post goes to moderation as a Pull Request and appears on the site once approved.

**Via git** — a Pull Request with `posts/<section>/<slug>.md` (sections: prompts, skills, cases, hooks, plugins, settings, mcp, agents). Installable skills — `plugins/<plugin>/skills/<skill>/SKILL.md`.

Section lists and the sidebar are generated automatically.
